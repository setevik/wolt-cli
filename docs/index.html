Features

Small tool, complete picture

Four commands: config, sync, report and export. Nothing to host, nothing to sign up for.

Incremental sync

The first sync downloads your full history. After that only new orders are fetched, politely paced to avoid rate limits.

Spending overview

Lifetime total, this year against the same period last year, the last 12 months and a monthly chart split by category.

The fee reality check

See exactly how much went to delivery and service fees, per order and in total, next to the price of the food itself.

Habits and patterns

A year-long activity calendar, busiest weekday, late-night orders, top venues, most ordered dishes and the cities you ordered in.

Searchable order list

Filter by venue, dish, city, type, currency or date range. Expand any order for its items and cost breakdown, then export to CSV.

Multiple currencies

Ordered abroad? Each currency gets its own totals instead of being added together. Switch between them in one click.

Is it for you?

A good fit, or not quite

wolt-cli is a small, focused tool. Here is an honest summary to help you decide before installing anything.

Good fit if you

  • Order on Wolt regularly and want the real totals, not a guess.
  • Want your data to stay local. Orders are stored in a file on your computer and the report works offline once opened.
  • Are comfortable with a terminal and have Node.js 20 or newer installed.
  • Like to dig into details: search, filter, and export to a spreadsheet for your own analysis.
  • Order in more than one country and want amounts kept separate by currency.

Probably not for you if you

  • Want a one-click app. You need to copy a login token from your browser's developer tools, and it expires, so you'll repeat that now and then.
  • Need budgets, alerts or a mobile app. This is a report you generate, not a service that watches your spending.
  • Use other delivery apps too. Only Wolt is supported.
  • Need guaranteed stability. It relies on Wolt's unofficial web API, which can change without notice.
  • Want currency conversion. Totals are per currency; nothing is converted to a single figure.

Get started

From zero to report in three steps

Requires Node.js 20.12 or newer. Want to look around first? npm run demo builds a report from sample data without a Wolt account.

  1. Install

    Clone the repository and link the command.

    git clone https://github.com/setevik/wolt-cli.git
cd wolt-cli
npm install
npm link

  2. Add your token

    Log in at wolt.com, open developer tools → Network, visit Order history, and copy the Authorization header of the order_history request.

    wolt-cli config   # paste the token; it's checked before saving

  3. Sync and open your report

    The first sync fetches details for every order, roughly two seconds each, so a few hundred orders take several minutes. Later syncs are quick.

    wolt-cli sync
wolt-cli report --open

Privacy & FAQ

Where your data goes

Your token
Stored only in ~/.wolt-cli/config.json and sent only to Wolt's own API.
Your orders
Saved to ~/.wolt-cli/orders.json. Nothing is uploaded anywhere else.
The report
A single self-contained HTML file with your data inside. The only external request it makes is loading the Chart.js library from jsDelivr to draw the charts.
No telemetry
No analytics, no accounts, no servers. Read the source; it's small.
Why do I have to copy a token by hand?

Wolt's bot protection blocks automated logins, so the tool uses the session token from your own browser. When it expires, wolt-cli sync fails and you run wolt-cli config again.

Can I share my report?

You can, but remember it contains your full order history. For showing the tool to others, share the demo instead: wolt-cli demo creates one from made-up data.

Does it work in my country?

It should work anywhere Wolt does. Amounts are grouped by the currency you paid in, and the report shows the cities you ordered from.

Can I analyse the data elsewhere?

Yes. wolt-cli export writes a CSV with date, venue, items, amount, currency, fees, city and status, ready for any spreadsheet.
